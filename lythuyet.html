BÁO CÁO PHÂN TÍCH TƯ DUY LÝ THUYẾT

Đề Số 1 - Học phần: Lập Trình Web (Tổng điểm: 40 điểm)

Câu 1 - 10 Điểm

Phân Tích Chi Tiết position: relative vs position: absolute

1. Sự khác biệt bản chất trong Luồng Tài Liệu (Document Flow):

  • position: relative: Phần tử vẫn giữ nguyên vị trí ban đầu trong luồng tài liệu chuẩn. Khi điều chỉnh top, left, right, bottom, phần tử sẽ di chuyển tương đối so với vị trí gốc của nó nhưng không làm thay đổi hay xô lệch các phần tử xung quanh.
  • position: absolute: Phần tử hoàn toàn bị tách khỏi luồng tài liệu chuẩn (được coi như không tồn tại đối với các phần tử khác). Vị trí của nó được tính dựa trên phần tử cha gần nhất có position khác static.

2. Ví dụ ứng dụng Responsive Layout (Thẻ thông báo Badge trên Nút bấm):

/* CSS Layout Responsive */
.btn-wrapper {
    position: relative; /* Làm mốc tọa độ cho thẻ con */
    display: inline-block;
}

.notification-badge {
    position: absolute; /* Tách khỏi luồng, ghim vào góc trên bên phải */
    top: -8px;
    right: -8px;
    background-color: #e74c3c;
    color: white;
    border-radius: 50%;
    padding: 3px 7px;
    font-size: 12px;
    font-weight: bold;
}
Thảo luận về Deploy Hosting & Độ tương thích thiết bị:
Khi website deploy lên hosting để hoạt động thực tế trên đa dạng thiết bị (Mobile, Tablet, Desktop), nếu lạm dụng position: absolute với đơn vị cố định (px) sẽ khiến giao diện bị vỡ (layout overflow). Giải pháp tối ưu responsive là luôn bao bọc phần tử absolute trong thẻ chứa relative kết hợp với Media Queries và đơn vị tương đối.
Câu 2 - 10 Điểm

Quy Trình Đăng Ký Domain, Cấu Hình Hosting & An Ninh Mạng

1. Quy trình 3 bước triển khai Website đơn giản:

  1. Đăng ký Domain (Tên miền): Lựa chọn tên miền từ nhà cung cấp (Namecheap, GoDaddy, PA Việt Nam).
  2. Khởi tạo Hosting: Cấu hình dịch vụ lưu trữ để đăng tải các tệp tin website.
  3. Trỏ Domain về Hosting: Thiết lập bản ghi A Record hoặc cập nhật Nameservers.

2. Vai trò của hệ thống phân giải tên miền DNS:

DNS đóng vai trò như một "danh bạ Internet", chuyển đổi tên miền dạng chữ (ví dụ: khanh152.github.io) thành địa chỉ IP dạng số để máy tính thiết lập kết nối.

3. Đề xuất 2 nền tảng Serverless Deployment:

  • GitHub Pages: Miễn phí, triển khai trực tiếp từ kho lưu trữ Git, tích hợp sẵn SSL.
  • Netlify: Hỗ trợ kéo-thả và tự động build dự án khi nhận code mới.
Rủi ro bảo mật do cấu hình sai:
Nếu thiếu chứng chỉ HTTPS (SSL/TLS), luồng dữ liệu truyền giữa trình duyệt và máy chủ sẽ ở dạng văn bản thô, dễ bị tấn công đánh cắp thông tin (Man-In-The-Middle).
Câu 3 - 10 Điểm

So Sánh let, const, var & Kỹ Thuật Debug

1. Bảng so sánh toàn diện Scope và Hoisting:

Tiêu chí var (ES5) let (ES6) const (ES6)
Phạm vi (Scope) Function Scope Block Scope {} Block Scope {}
Hoisting Có (gán giá trị undefined) Có (Temporal Dead Zone) Có (Temporal Dead Zone)
Tái gán giá trị Cho phép tái gán & khai báo lại Cho phép tái gán, không khai báo lại Không cho phép gán lại

2. Tình huống lỗi kinh điển do dùng var trong vòng lặp bất đồng bộ:

// LỖI: Dùng var khiến biến i bị đè trong cùng 1 Function Scope
for (var i = 1; i <= 3; i++) {
    setTimeout(function() {
        console.log("Giá trị i: " + i); // Kết quả in ra: 4, 4, 4 (Sai kỳ vọng)
    }, 1000);
}

// SỬA LỖI: Thay var bằng let (Block Scope giữ giá trị riêng cho mỗi vòng lặp)
for (let j = 1; j <= 3; j++) {
    setTimeout(function() {
        console.log("Giá trị j: " + j); // Kết quả in ra đúng: 1, 2, 3
    }, 1000);
}

3. Quy trình Debug với Chrome DevTools:

Nhấn F12 chọn tab Sources $\rightarrow$ Chọn file script và click vào chỉ số dòng code để đặt Breakpoint $\rightarrow$ Quan sát biến tại bảng Scope.

Câu 4 - 10 Điểm

Kỹ Thuật Event Delegation & Tối Ưu Hóa Hiệu Năng DOM

1. Bản chất của Event Delegation (Ủy quyền sự kiện):

Dựa trên cơ chế Event Bubbling (sự kiện nổi bọt từ con lên cha). Thay vì gán nhiều listener cho từng thẻ con, ta chỉ gán duy nhất 1 listener ở thẻ cha.

2. Minh họa ứng dụng xử lý danh sách động:

<!-- Danh sách động chứa sản phẩm -->
<ul id="productContainer">
    <li class="item">Sản phẩm 1</li>
    <li class="item">Sản phẩm 2</li>
</ul>

<script>
// Chỉ gán 1 sự kiện duy nhất ở thẻ cha <ul>
document.getElementById('productContainer').addEventListener('click', function(event) {
    if (event.target && event.target.matches('li.item')) {
        console.log('Đã chọn:', event.target.innerText);
    }
});
</script>
Lợi ích tối ưu hiệu năng Website:
  • Giảm thiểu bộ nhớ (RAM): Tránh việc khởi tạo quá nhiều Event Listeners.
  • Hỗ trợ phần tử sinh ra động: Các thẻ thêm mới tự động nhận sự kiện mà không cần gán lại.
